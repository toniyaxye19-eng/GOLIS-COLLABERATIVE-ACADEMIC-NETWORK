# GCAN — Qorshaha Horumarinta (Roadmap)

## Himilo
Arday walba oo GCAN ah wuxuu helaa meel uu ka helaan aqoon kororsi, uu ku wadaagi
fikrado, isla markaana uu is caawiyo isla markaana is dhiirrigeliyo — courseyada
PPH, Anatomy, Physiology, Pathology, iyo Microbiology.

## Marxalad 1 — Demo (kan hadda) ✅
- [x] Landing page: ujeeddada, features, iyo courseyada
- [x] Bogga courseyada: revision + taba-baro (quiz) course kasta
- [x] Doodaha (discussion): su'aalo + jawaabo (demo localStorage)
- [x] Agabka (materials): maktabad demo ah
- [x] Dhinaca UI: Somali buuxa, mobile-friendly

## Marxalad 2 — Accounts + Backend
- [ ] Email / phone login (arday Golis keliya)
- [ ] Profile arday (class-ka, courseyada uu qaadanayo)
- [ ] Doodaha iyo agabka waxay noqonayaan kuwo wadajir ah (database)
- [ ] Admin: macallimiin / qof ka tirsan GCAN oo maamulaya content-ka

## Marxalad 3 — Content
- [ ] Revision notes buuxa course kasta (marxalad walba)
- [ ] Imtixaanno hore (past papers) course kasta
- [ ] Quiz-yo cusub toddobaadkii
- [ ] Video sharaxaad oo gaaban (5-10 daqiiqo) mawduuc kasta

## Marxalad 4 — Barwaaqo
- [ ] Study groups (kooxo yar oo class dhexdisii ah)
- [ ] Leaderboards / badges si loo dhiirrigeliyo
- [ ] PWA / mobile app (offline revision)
- [ ] Mentorship: ardayda sanadka dambe iyo kuwa hore
