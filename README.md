# GCAN — Golis Collaborative Academic Network

**Balanteena waa GOLIS COLLABORATIVE ACADEMIC NETWORK.** Gacmo wadajir bay wax ku gooyaan.

## Waa maxay GCAN?

GCAN waa shabakad ardaydu leeyihiin, kana heli doonaan aqoon kororsi, ay ku wadaagi
doonaan fikrado iyo waayo-aragnimo waxbarasho oo ardayda dhexdood ah. Ardaydu way
is caawiyaan, is dhiirrigeliyaan, isla markaana si wadajir ah uga tashadaan
aayahooda iyo mustaqbalkooda.

## Waxa uu bixiyaa

- **Revision** — cheat-sheets, ceqaabyo, iyo su'aalo imtixaan
- **Taba-baro** — quiz-yo ay ardaydu isku dhiirrigeliyaan
- **Agab waxbarasho** — maktabad wadajir ah (buug, slides, imtixaanno hore)
- **Discussion** — dood class dhexdisii ah oo kasta

## Sida loo shubo (hadda — demo)

Mashruucan waa app HTML/CSS/JS oo aan build u baahnayn:

```bash
# furo index.html browser-kaaga, ama:
python3 -m http.server 8080
# kadib fur http://localhost:8080
```

Fiiro gaar ah: xogta demo (doodaha iyo agabka) waxay ku kaydsan tahay
`localStorage` browser-kaaga — arday kastaa wuxuu arkayaa xogtiisa unugii
(server weli ma jiro, tan hoose ayaad ka aragtid qorshaha).

## Qorshaha (Roadmap)
